# API reference

The reference is generated from the source type annotations and docstrings at
build time.

- [Device](device.md) documents connection, acquisition, and configuration
  operations.
- [Data records](data.md) documents values returned by `data_buf()` and the
  spectrum and alarm-limit containers.
- [Enums](enums.md) documents event, display, and control values intended for
  application code.
