# API reference

The reference is generated from the source type annotations and docstrings at
build time.

- [Device](device.md) documents connection, acquisition, and configuration
  operations.
- [Data records](data.md) documents values returned by `data_buf()`, the
  spectrum and alarm-limit containers, the flash descriptor, the `SET_EXCHANGE`
  interface descriptor, and the typed status / record flag bitmasks.
- [Enums](enums.md) documents event, display, interface, and control values
  intended for application code.
